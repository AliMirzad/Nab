# شواهد بررسی ناب

تاریخ: ۱۹ اکتبر ۲۰۲۶ / ۲۷ مهر ۱۴۰۵.

## بررسی محلی پس از تغییر نام و بازبینی

| بررسی | نتیجه ثبت‌شده |
| --- | --- |
| سرور | `mvn clean verify` موفق؛ JAR با نام `nab-api-1.0.0.jar` ساخته شد |
| تست سرور | ۳۶ تست موفق: ۱۳ سینک/اعتبارسنجی/عکس، ۶ گزارش، ۱۰ برنامه‌ریز، ۷ API برنامه هفتگی |
| دیتابیس تست محلی | H2 در حالت سازگار با PostgreSQL؛ PostgreSQL واقعی در CI پیکربندی شده و باید نتیجه اجرای آن جدا دیده شود |
| وب | ۳ تست ساعت تهران، TypeScript و build نهایی Vite موفق |
| اپ | `flutter analyze`: بدون مورد؛ ۱۳ تست SQLite/مسیر/صف/receipt موفق |
| اتصال واقعی اپ/سرور | اجرای انتخابی روی نسخه ناب موفق؛ گشت آفلاین، بازیابی دیتابیس، قطع receipt پس از commit، replay و عکس کنترل شد؛ در اجرای پیش‌فرض عمداً skip است |
| ابزار Android | `flutter doctor -v`: Android SDK پیدا نشد؛ ساخت APK محلی تأیید نشده |
| دستگاه واقعی | دوربین، GPS، قفل صفحه، باتری، force-stop و نصب واقعی بررسی نشده‌اند |
| iOS | متوقف؛ ساخت یا پذیرش اجرا نشده |
| Docker/production | فایل‌ها موجودند؛ اجرای Compose و استقرار عمومی این تحویل تأیید نشده |

تست‌های گزارش فایل واقعی PDF و XLSX را می‌سازند، XLSX را بازخوانی می‌کنند و PDF را برای بررسی به تصویر تبدیل می‌کنند. این نمونه‌ها در `backend/target/report-qa` هستند و فایل خروجی/داده مشتری محسوب نمی‌شوند؛ وارد مخزن نمی‌شوند.

## شواهد مرحله‌های قبلی

فرم مسیر مرتب و برنامه هفتگی از مرورگر واقعی ساخته شدند. الگوی ۰۲–۰۴ و ۰۶–۰۸ با چرخه ۲۴/۲۴ در هفته اول ۴ شیفت/۸ نوبت و در هفته بعد ۳ شیفت/۶ نوبت داشت. گزارش ماه شمسی، فیلتر نگهبان/مسیر و دانلود هر دو قالب نیز در مرورگر و API بررسی شده‌اند. این شواهد مربوط به محیط دمو هستند، نه پذیرش گوشی مشتری.

## CI و ساخت Android

گردش کار `Check Nab` تست سرور روی PostgreSQL، تست/build وب و تحلیل/تست Flutter را اجرا می‌کند. `Android build` روی تغییرات Android/Flutter در شاخه main یا اجرای دستی، APK debug می‌سازد و فقط در صورت موفقیت artifact `nab-android-debug` را نگه می‌دارد. نتیجه و فایل واقعی را در Actions همان commit بررسی کنید؛ «پیکربندی‌شده» را «اجرا و موفق‌شده» حساب نکنید.

برای تکرار آزمون اتصال فقط روی دیتابیس دمو:

```powershell
cd mobile
flutter test test/api_contract_test.dart --dart-define=NAB_INTEGRATION_URL=http://localhost:8080
```

این آزمون داده آزمایشی ایجاد می‌کند. برای نتیجه قابل استناد، commit، دستور، تاریخ، سیستم‌عامل و مدل گوشی را همراه نتیجه ثبت کنید.

# وضعیت محصول ناب

مبنای وضعیت: ۱۹ اکتبر ۲۰۲۶. «پیاده‌شده» به معنی وجود منطق و رابط است، نه تأیید همه شرایط گوشی و production.

| قابلیت | وضعیت | حدود و نکات |
| --- | --- | --- |
| پنل فارسی و نقش‌ها | پیاده و محلی بررسی‌شده | یک نصب برای یک سازمان؛ سرپرست همه محل‌ها را مدیریت می‌کند |
| کاربران/محل/چک‌پوینت/QR | پیاده | ایجاد و فهرست؛ فعال/غیرفعال کاربر؛ ویرایش/حذف جامع هنوز نیست |
| مسیر مرتب و حلقه‌ای | پیاده و تست‌شده | شروع/پایان و ترتیب اجباری در اپ و سرور |
| مأموریت زمان‌دار | پیاده | هر مأموریت یک اجرای یکتا و snapshot مستقل دارد |
| برنامه ۲۴/۲۴ | پیاده و تست‌شده | کار/استراحت قابل تنظیم، نوبت فقط داخل شیفت |
| الگوی ساعت‌های هفته | پیاده و تست‌شده | روزهای تکرار، عبور از نیمه‌شب، پیش‌نمایش و ساخت کل بازه |
| استفاده برای هفته بعد | پیاده و تست‌شده | حفظ anchor و منع بازه تکراری/هم‌پوشان همان الگو؛ نه تولید بی‌پایان پس‌زمینه |
| کد اپ Android | پیاده، تحلیل و تست منطق | ساخت native و آزمون سخت‌افزار جداگانه لازم است |
| اجرای آفلاین | منطق و تست اتصال پیاده | ورود و دریافت اولیه آنلاین است؛ حذف نصب صف را پاک می‌کند |
| سینک دستی و خودکار | پیاده | receipt رویداد و عکس؛ پس‌زمینه تابع سیستم‌عامل |
| GPS | پیاده | نبود/قدمت/کم‌دقتی مسدودکننده نیست؛ روی گوشی واقعی تأیید نشده |
| حادثه و عکس | پیاده و تست ارتباط | دسترسی خصوصی، retry و جلوگیری از receipt کاذب |
| نقشه و جزئیات گشت | پنل پیاده | آخرین داده رسیده به سرور؛ آفلاین نمایش لحظه‌ای ندارد |
| گزارش PDF و Excel | پیاده و تست‌شده | شخص/محل/مسیر/نوبت/وضعیت/ماه شمسی/بازه؛ جزئیات اختیاری |
| NFC و RFID | پیاده نشده | نسخه فعلی فقط QR است |
| Push و SOS | پیاده نشده | در محدوده فعلی نیست |
| چندسازمانی و سطوح محل | پیاده نشده | مجوزها فعلاً در سطح نقش کل نصب‌اند |
| APK نصب‌شده و پذیرش گوشی | تأیید نشده | نتیجه ساخت Android در Actions و سپس نصب واقعی بررسی شود |
| iOS | متوقف | اسکلت اولیه حفظ شده؛ ساخت و تحویل تأییدشده ندارد |
| استقرار اینترنتی | انجام نشده | Docker/Compose آماده، نه سرویس منتشرشده |

## اجزای ساخته‌شده

Java/Spring Boot، React/TypeScript، Flutter/Dart، SQLite گوشی، Flyway، H2 محلی، تنظیم PostgreSQL، تولید گزارش POI/PDFBox، فونت فارسی محلی، فایل‌های Docker و گردش کار بررسی/ساخت Android.

## داده و حساب

داده موجود محلی، نمونه و آزمون است و موقعیت واقعی مشتری نیست. رمزهای README مخصوص دیتابیس دمو هستند؛ نشست‌ها، تصاویر و دیتابیس وارد مخزن نمی‌شوند. پس از clone، محیط دمو از نو ساخته می‌شود.
